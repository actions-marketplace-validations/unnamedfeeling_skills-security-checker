# Data Analyst Skill

This skill allows agents to inspect structured datasets and summarize key metrics.

## Guidelines
1. Read input CSV or JSON data provided in the workspace.
2. Calculate count, mean, median, and null value percentages.
3. Output a clean markdown summary table.
4. Never modify original data files.
